# Template: straightforward-nugget-list

Output shape for `os-gold/modes/straightforward.md`. Markdown.

```markdown
# [Brief descriptive title — 4-8 words max]

## [Optional thematic subheading — only if nuggets cluster naturally]

**[Nugget 1 — bold single-line articulation, stands alone]**
- [expansion bullet]
- [expansion bullet]
- [expansion bullet]

**[Nugget 2]**
- [expansion bullet]
- [expansion bullet]

## [Next thematic subheading if used]

**[Nugget N]**
- [expansion]
- [expansion]
...
```

## Rules

- **Title only.** No intro, no description, no preamble about what was extracted.
- **Thematic subheadings are optional.** Use only if the nuggets cluster naturally. If not, flat list.
- **Bold line = the shareable insight.** Should be quotable, stand-alone, memorable.
- **2–5 bullets per nugget.** Less than 2 is underweight. More than 5 is over-expanded and the nugget loses its punch.
- **No outro.** When the last nugget is done, stop.
- **No emojis.**

## What the bullets should do

- Clarify what the nugget means (without summarizing the source)
- Expand its implications
- Give a concrete example IF it sharpens the nugget. Skip if it would just pad
- Connect to related ideas the source touches on

## What the bullets should NOT do

- Quote the source at length (one quoted phrase is fine, a paragraph is not)
- Editorialize ("This is a great insight because...")
- Cross-reference other nuggets ("See nugget 3" clutters the list)
