# Architecture Question Types

## Boundary

- where should responsibility live?
- what interface should be stable?

## Decomposition

- how do we split this without teaching the wrong architecture?

## Integration

- what contract or wiring risk exists across systems?

## Migration

- how do we move from old to new safely?

## Contract Risk

- where could a consumer break if this interface shifts?
- which behaviors are implicit and undefended?

## System Cleanup

- what cleanup is structural vs incidental?

## Rule

Name the question type first so the answer does not drift into generic advice.
