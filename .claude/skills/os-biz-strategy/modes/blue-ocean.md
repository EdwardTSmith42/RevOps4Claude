# Mode: blue-ocean

## Purpose

Apply Kim & Mauborgne's Blue Ocean Strategy toolkit to help a user find or shape uncontested market space. Modular — the mode supports six entry points and uses different frameworks depending on where the user is in the strategic process. Produces strategic artifacts (value curve maps, ERRC summaries, noncustomer tiers, GTM blueprints) rather than finished copy.

## Triggers

Phrases like: *"blue ocean analysis,"* *"value innovation,"* *"uncontested market space,"* *"escape red ocean,"* *"help me find new demand,"* *"apply ERRC to my offer,"* *"strategy canvas,"* *"six paths,"* *"who else could buy this,"* *"investor-ready strategy,"* *"strategic pivot."*

Also triggers when another skill needs a strategic pressure-test or a noncustomer-tier analysis.

## Inputs

See `references/market-input-context.md`. This mode specifically benefits from:

- **Required:** The offer + some framing of the strategic question (what the user is trying to figure out)
- **Strongly preferred:** An entry point — which of the six (Idea Ignition / Market Saturation Escape / Tool Activation / Customer Growth Hunt / GTM Friction Removal / Investor Readiness) matches their question. If unclear, ask.
- **Strongly preferred:** What's been tried — prior strategic moves and their outcomes
- **Optional:** Competitive landscape info, current value propositions, recent market data

If the entry point is unclear, open with the entry-point menu (see `templates/blue-ocean-output.md` for the opening format).

## Run

The mode is modular. Execution varies by entry point but follows this general arc:

**Step 1 — Establish entry point.** If the user hasn't named one, present the six entry points (Ignite Idea / Escape Saturation / Tool Activation / Expand Demand / Break GTM / Investor Readiness) and ask where they want to begin. If the user's question clearly maps to one, skip the menu and proceed.

**Step 2 — Select toolkit artifact(s).** Based on the entry point, choose which of the Kim/Mauborgne tools to apply:
- **Ignite Idea** → often Strategy Canvas + ERRC Grid + Six Paths
- **Escape Saturation** → Strategy Canvas + ERRC Grid (especially Eliminate/Reduce)
- **Tool Activation** → whichever specific tool the user asked for
- **Expand Demand** → Three Tiers of Noncustomers + Buyer Utility Map
- **Break GTM** → Adoption Hurdles Map + Tipping Point Leadership
- **Investor Readiness** → Strategy Canvas + ERRC + Price Corridor + artifact-grade materials

See `references/market-frameworks.md` for the full toolkit catalog.

**Step 3 — Apply the artifact.** Work through the chosen framework with the user's specific offer and context. Produce the canonical shape for each artifact per `templates/blue-ocean-output.md`.

**Step 4 — Run strategic overlays (optional but recommended).** For strategic outputs that will drive real decisions, apply one or more adversarial overlays:
- **Inverse Thinking** — flip assumptions, test which claims have evidence
- **Skeptical Investor Review** — role-play a VC pressing on unit economics, market size, defensibility
- **Forced Trade-offs** — name what the strategy explicitly *isn't* doing, and why

Overlays run *after* the primary analysis, not in parallel. They're pressure-tests to detect strategic fragility before it's real. See `references/market-frameworks.md`.

**Step 5 — Land on concrete next moves.** Every Blue Ocean output should end with concrete strategic actions the user can take, not abstract principles. If the output doesn't compile to action, the analysis isn't done.

**Tonal discipline throughout:** collaborative but firm. Challenge as much as support. Don't yes-and. Provide concrete next steps and outputs after every insight, not just analysis for its own sake.

## Output

Per `templates/blue-ocean-output.md`. The mode is modular — the exact shape depends on which artifact(s) the user's question called for. Opening with the entry-point menu is also a valid output when the user hasn't specified where to begin.

After output, include a brief cross-mode suggestion block, separate from the artifact. Pick the one or two adjacent modes that would sharpen what just shipped, and describe the effect rather than reciting a fixed line. Common next moves: formalizing the counter-positioning into messaging language (`positioning`), reading sophistication / awareness / temperature for the same offer (`market-map`), or capturing the strategic insight into a memorable visual framework (`models-method`).

## Design Rationale

- **Start-anywhere entry design** — users arrive from different problems. Forcing a fixed sequence misaligns with where they actually are. The modular toolkit matches how strategic work really happens.
- **Toolkit and overlays are distinct** — toolkit = divergent-generation (ERRC, Six Paths, Noncustomer Tiers produce new options). Overlays = adversarial pressure-testing (Inverse Thinking, Skeptical Investor, Forced Trade-offs test existing options). Confusing the two produces either brainstorming without rigor or critique without creation.
- **Artifact orientation** — Blue Ocean work produces tangible deliverables (value curve maps, ERRC summaries, noncustomer personas, GTM blueprints), not conclusions. Modular artifacts can be reused, recombined, and communicated across stakeholders.
- **Collaborative but firm** — the mode challenges as much as it supports. A yes-and partner produces soft strategies. Disagreement and counterproposals are part of the value; constant contrarianism is not.
- **Always compile to concrete next moves** — every insight ends with a concrete next step. If the output is purely analytical, the mode failed its job.
- **The four implicit role-dimensions** — framework rigor (Strategist), creative divergence (Innovation Coach), adversarial critique (Provocateur), and artifact generation (System Builder) are real task-types the mode covers, not personas to cosplay. Different sections of the output lean on different dimensions; the mode shifts register as the work calls for it.
