# Offer Brainstorm — canonical output shapes

Use this shape for `modes/offer-brainstorm`. Two patterns: **breadth** (10-category catalog, ~40 named offer ideas) and **depth** (Hormozi-style 3 fully-fleshed offers). Mode default is breadth. Depth is requested explicitly or chained as a follow-up after the user picks from breadth.

## Key rules

- **Named offers in quotes.** Every offer has a specific, memorable name — not *"online course about X"* but *"6-Figure Coach Blueprint"*. Names should be credible and concrete. Avoid generic ("Mastery System") and over-the-top ("Ultimate Quantum Success Matrix").
- **Brief description + bullet points** for each offer. The brief is one sentence of positioning. Bullets cover 1-2 distinguishing features.
- **Comprehensive AND varied.** Breadth pattern requires coverage of all 10 categories, not just the obvious 3-4. Non-obvious offers (Licensing, Alternative / Non-Obvious) are as important as obvious ones (DIY, Coaching).
- **All offers must have solid potential.** Don't stretch to fill a category with a weak offer. If a category genuinely doesn't apply to this audience/offer, a one-line note saying so is the correct content for that category — never fabricate to hit coverage.
- **The filter leaves a visible trail.** Offers cut by the four-criteria filter appear in the Filtered Out section with a one-line reason each. A filter with no visible output is indistinguishable from a filter that never ran.
- **Depth pattern uses the obstacle-as-solution formula** verbatim: *"[NAME]: How to [YAY] without [BOO] even if you [GREATEST OBSTACLE]"*. Formula preserves the specific psychological move.
- **Depth pattern grounds offers in the Value Equation** — each offer touches Dream Outcome + Perceived Likelihood + Time Delay + Effort. See `../../_shared/references/hormozi-value-equation.md`.
- **Hormozi's four offer-worthy criteria** apply — filter candidates for massive pain + purchasing power + easy to target + growing market. See `../references/offer-frameworks.md`.
- **Chain hint at the end.** Close with explicit pointer to the natural next step (map the market, flesh out the vehicle, positioning work).

## Grounding check before shipping

1. Is every offer grounded in specific input (avatar + offer context), not generic market platitudes?
2. Are all 10 categories populated or explicitly noted as not-applicable in breadth pattern? Is the Filtered Out section present? Are all 3 offers + 5 delivery vehicles + sub-offers present in depth pattern?
3. Do the offer names pass the credibility check (no over-the-top, no generic, no benefit-creep)?
4. Is the output traceable to input? Can the user see where an offer came from?
5. If any category was fabricated to hit coverage, is that flagged rather than shipped?
